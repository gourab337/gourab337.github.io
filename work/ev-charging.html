Real-time EV charging pipeline

MQTT → DuckDB → live map, for 433 NSW fast chargers.

Every number on this page comes from the event stream the pipeline actually recorded: 40,853 price, session and meter events, published over MQTT with QoS 1, stored in DuckDB by the subscriber, and checked end to end. Press play to watch the day stream in, drag the slider to jump in time, and click a charger to see its live sessions.

About the code. This was a team project, so the source is not mine alone to publish and the repository stays private. This page is a browser replay of the recorded stream, not the production app. I can walk through the architecture and code in a discussion. Charger locations, operators and power ratings are real public data; prices and charging sessions were simulated from real NSW wholesale prices.

How the real pipeline works

simulator → event builder → publisher (QoS 1) → Mosquitto → subscriber → DuckDB → Dash + Leaflet dashboard
  • Events. A simulator produced a day of hourly prices and charging sessions for every DC charger in a cleaned NSW charger database. The event builder turns them into ordered price-change, session start/end and per-minute meter events, and keeps only real price changes.
  • Publishing. A paced QoS 1 publisher writes an fsynced acknowledgement log and checkpoints, so after a crash it resumes from the last acknowledged message. Prices are retained messages, so a new subscriber gets current prices straight away, and a last-will topic reports when the publisher goes offline.
  • Ingest. The subscriber uses a persistent session, ignores duplicate deliveries by event id, tracks an event-time watermark to flag late events, quarantines malformed messages, and commits in batches to DuckDB.
  • Serving. The dashboard only reads committed state, so every number on screen has been stored first.
  • Verification. 33 automated checks compare what was prepared, published and stored. In the recorded run, 40,853 of 40,853 events arrived, with 0 rejects and 0 late events.

Stack: Python, paho-mqtt, Mosquitto, DuckDB (spatial), Dash, dash-leaflet. Built in 2026 at the University of Sydney.
